Internal Labs

A collection of intentionally vulnerable web security labs that I build locally to understand vulnerabilities, exploit techniques, and—most importantly—how to fix them in real code.

The goal is to learn vulnerabilities from both sides:

Attacker → Understand the vulnerability → Developer → Implement the fix

🎯 Goal

I'm building these labs to practice identifying common security vulnerabilities and understand what actually happens inside the vulnerable application.

Each lab contains:

🐞 An intentionally vulnerable implementation 

🔎 A practical way to reproduce the vulnerability

🧪 Exploitation examples

🛡️ A fixed/secure implementation

📚 Notes explaining why the vulnerability occurs

🔧 Recommendations for preventing it
